## 🍔 Projeto em destaque: DEV BURGUER API

<p align="center">
  <img src="./assets/dev-burguer-api.png" alt="Captura de tela do projeto DEV BURGUER API em desenvolvimento" width="850" />
</p>

O **DEV BURGUER API** é um projeto back-end para o gerenciamento de uma aplicação de pedidos. Ele foi construído como uma jornada prática para estudar a estrutura de uma API, autenticação, permissões, produtos, categorias e pedidos.

### Principais funcionalidades

- Cadastro e autenticação de usuários com senha protegida.
- Login com tokens JWT e middleware de autenticação.
- Controle de acesso para usuários administradores.
- Validação de dados e prevenção de e-mails e categorias duplicados.
- CRUD de produtos e categorias.
- Relacionamento entre produtos e categorias por chaves estrangeiras.
- Upload de imagens para produtos e categorias.
- Criação e atualização de ofertas.
- Registro e atualização de pedidos no MongoDB.

### Stack e conceitos praticados

| Área | Tecnologias e conceitos |
| --- | --- |
| Back-end | JavaScript, Node.js, API REST, arquitetura MVC |
| Segurança | Hash de senha, JWT, middlewares de autenticação e admin |
| Dados | Sequelize, migrations, models, relacionamentos entre tabelas e MongoDB |
| Qualidade e arquivos | Yup, Biome.js e Multer |
| Ambiente | Docker e containers |

### O que aprendi com o projeto

Este projeto reforçou conceitos importantes sobre a conexão entre as partes de uma API: models, controllers, validações, rotas, middlewares e persistência de dados. A principal evolução foi sair do foco em apenas “fazer funcionar” e começar a pensar em uma estrutura clara, segura e preparada para crescer.
